## 固定风格锚定词（所有输出必须包含）

3D 动画渲染，赛璐珞质感，电影级打光，高细节材质

**轮廓线条（所有输出必选）：**

清晰轮廓线，明快卡通渲染，轮廓线均匀一致，无断线无粗糙边缘

**材质质感（含材质镜头时必选）：**

高细节材质，写实材质与卡通比例结合，材质纹理清晰，表面质感细腻

**光影层次（含光影场景时必选）：**

柔和光影层次，明暗对比清晰，光效柔和自然，暖色调主导

愉悦治愈氛围，3D 动画美学，温馨情感表达，现代都市风情

**画质锁定词（所有输出必须包含，置于风格收尾之后）：**

## 美学禁止项（生成时严格规避）

以下词汇/风格不得出现于输出提示词中：

- ❌ 写实渲染/照片级真实感风格
- ❌ 暗调/重阴影/过度对比风格
- ❌ 高饱和荧光色/霓虹色系
- ❌ 现代元素缺失（必须明确现代场景）
- ❌ 卡通比例、大眼睛、Q版等变形描述
- ❌ 赛博朋克/蒸汽朋克/架空西幻元素
- ❌ 画外叠加文字（字幕、水印、标题卡、旁白叠字等 UI 层文字，画面必须为纯视觉画面）

> 💡 **例外**：故事世界内的道具文字（招牌、路牌、标识、书籍等场景中自然存在的文字）**不属于禁止范围**。当分镜画面描述中包含此类内容时，应如实描写其存在并要求文字清晰。

## 摄影机语言词库（3D 动画运镜）

在 cameraDirection 字段中使用以下标准词汇（3D 动画虚拟摄影机与真人运镜术语完全对应）：

| 运镜类型 | 标准写法 |
|---|---|
| 固定 | `固定镜头（locked-off），画面无运动` |
| 横向追踪 | `侧面tracking shot，跟随角色匀速横移，背景向后流动` |
| 推近 | `缓慢dolly in推近，起幅[景别]→落幅[景别]，目的：[叙事目的]` |
| 拉远 | `缓慢dolly out拉远，起幅[景别]→落幅[景别]，目的：[叙事目的]` |
| 环绕 | `counter-clockwise orbit [X]度，以[主体]为圆心，展示空间纵深` |
| 仰拍 | `低角度仰拍固定，目的：[叙事目的]` |
| 俯拍 | `top-down 90度垂直俯拍固定，目的：[叙事目的]` |
| 水平摇移 | `水平pan [方向]，起幅[X]→落幅[Y]，目的：[揭示/跟随什么]` |

**格式要求**：cameraDirection 必须包含叙事目的：
`起幅[景别] → 运动方式+速度 → 落幅[景别]，目的：[揭示/跟随/强调什么]`

## 声音设计词库（3D 动画 · 愉悦治愈题材）

在 motionScript 动作轨迹之后可追加 `【关键音效】` 块，提升视频临场感：

格式：
```
0-Xs: [动作段] ... | 朝向：...
【关键音效】
底噪：[空间持续环境音]（全程持续）
事件音：[时间点][声源] "[音效描述]"
空间感：[声音方向/距离]
```

**底噪选择（愉悦治愈题材常用场景）：**
- 咖啡厅：`咖啡机研磨声+轻柔背景人声+窗外轻车声`（全程持续）
- 城市街道：`城市环境底噪+远处汽车+偶尔行人脚步`（全程持续）
- 居家室内：`空调低鸣+远处轻微环境音+衣料轻微摩擦`（全程持续）
- 公园/户外：`风声轻拂+虫鸣鸟叫+远处城市底噪`（全程持续）
- 办公室：`键盘打字声+空调低频嗡鸣+远处走廊脚步`（全程持续）
- 下雨天：`雨滴连续打在窗面+偶尔远雷`（全程持续）

**事件音词库（按动作类型）：**
- 步行：皮鞋 `"哒哒"踏在[地板材质]上` / 运动鞋 `"噔噔"木地板`
- 取放物品：咖啡杯 `"陶瓷轻碰木质桌面，清脆短促"` / 书本 `"纸张翻动细声"`
- 门：室内门轴 `"轻吱呀"` / 玻璃门 `"气封轻嗡"` / 推拉 `"滑轨低鸣"`
- 衣物：外套 `"布料窸窸窣窣"` / 皮质包袋 `"皮革轻摩擦"`
- 情感微动作：短促吸气 `"嗯"` / 轻笑 `"呵"` / 轻叹 `"哎"`
- 数码设备：手机震动 `"嗡嗡"` / 键盘按键 `"哒哒"` / 通知音 `"叮"`

**禁止**：在此块中写 BGM/配乐/弦乐（音轨后期统一叠加）
