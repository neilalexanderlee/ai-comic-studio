# 分镜字段完整格式规范

## 标准分镜块结构

```
**时间戳|场景标题**（用 | 分隔，标题简洁描述动作/情绪）

- **【背景音】** （音乐类型 + 情绪功能描述）
- **【运镜】** （英文摄影机指令，见下方）
- **【画面】** （角色动作 + 场景状态的视觉描述，中文）
- **【首帧】** （镜头第一帧的精确静止构图）
- **【尾帧】** （镜头最后一帧的精确静止构图）
- **【motionScript】** （AI视频生成分段时间轴；各段合计等于镜头时长）
- **【对白】** （如有；无对白的镜头可省略此字段）
  - 角色名(情绪/动作备注):「台词内容」
- **【音效】** （具体的声音事件，不能用通用描述）
- **【字幕】** （画面叠字，通常用于开场地点/时间或关键信息）

---
```

---

## 各字段详细规范

### 【背景音】
描述背景音乐的类型和情绪功能，不是具体曲名。

✅ 好的写法：
- `激烈战鼓，铜管冲刺，战斗主题强起`
- `轻柔钢琴，竖琴，温暖回忆音色`
- `管风琴低频，不和谐弦乐，黑暗主题`
- `低沉铜管渐起，英雄主题萌发`

❌ 禁止写法：
- `背景音乐`（太笼统）
- `悲伤的音乐`（没有乐器信息）

---

### 【运镜】
**必须用英文**，描述摄影机的物理运动。这是给 AI 视频生成模型看的摄影指令。

常用公式：
```
[运动方式] [起点] [方向/目标] [速度修饰]
```

**运动词汇：**
- `slow dolly in` / `slow dolly out` — 推轨向前/后
- `tilt up` / `tilt down` — 垂直倾斜
- `pan left` / `pan right` — 水平摇镜
- `tracking shot` — 跟拍
- `crane shot` — 升降镜
- `handheld` — 手持（晃动感）
- `static medium shot` — 静止中景
- `whip pan` — 快速摇镜（转场）
- `360 orbit` — 360度环绕
- `slow push in on [对象]` — 缓推特写某物

**角度修饰：**
- `low angle` / `high angle` / `eye level`
- `extreme close-up` (ECU) / `close-up` (CU) / `medium shot` (MS) / `wide shot` (WS) / `aerial` (空中)

✅ 示例：
- `slow push in from doorway to table`
- `low-angle tracking shot following axe swing + slow-motion impact`
- `360 orbit around four figures + quick cut inserts`
- `handheld chaos + quick cuts of panicking crowd`

---

### 【画面】
用中文描述**在这个镜头里发生了什么**：角色的动作、位置关系、场景状态。

**规则：**
1. 必须包含角色的**视觉ID字符串**（如"龙渊（黑甲银纹）"）
2. 描述动作/状态，不描述摄影机（摄影机在【运镜】里）
3. 25-60字为宜

✅ 示例：
```
龙渊（黑甲银纹）缓缓从椅子上站起，右手伸向靠在桌边的无名剑剑柄；
站定后，背上无名剑随姿势调整，宽刃大剑的剑柄高过头顶
```

---

### 【首帧】和【尾帧】
描述镜头**第一帧**和**最后一帧**的精确静止画面。这两帧用于 AI 图像生成（首帧引导镜头开始，尾帧锚定结束状态）。

**格式：** `[景别/角度]：[角色/场景的精确位置] + [表情/光线] + [情绪暗示]`

**规则：**
1. 首帧和尾帧必须**不同**，体现镜头的起止变化
2. 必须是**静止描述**，不能写运动（运动在 motionScript 里）
3. 光线描述：炉火橙光、逆光轮廓、月光蓝白、绿色毒雾漫射等

✅ 首帧示例：
```
龙渊坐姿，地图在桌面，他的右手已经离开地图，向剑柄方向移动，侧面低角度
```

✅ 尾帧示例：
```
龙渊站立全身，无名剑背在背上稳稳竖立，琥珀眼看向窗外，逆光轮廓清晰
```

---

### 【motionScript】
**这是系统解析、入库和视频生成的主驱动字段。字段名必须精确写成 `motionScript`，不得使用 `videoScript`。**

**格式硬约束：**
1. 使用 `0-Xs: [...]` 时间轴；每段 2-4 秒
2. 所有时间段之和必须精确等于该镜头时长
3. 每镜围绕一个核心动作，运镜织入动作段，不能写成纯摄影机描述
4. 角色首次出现时写角色名和视觉ID，并注明画面位置/姿态
5. 含台词时，把台词嵌入实际开口的时间段：`[角色名（动作）说：「台词」]`
6. 有命名角色时，整行末尾必须写 `｜朝向：角色名+朝向方位`
7. 不得写配乐、BGM、背景音乐；音乐只放在【背景音】字段

**朝向词库：**
- 正面面朝镜头
- 3/4侧面朝右 / 3/4侧面朝左
- 正侧面朝右 / 正侧面朝左
- 背对镜头

✅ 15秒标准示例：
```
0-3s: [龙渊（黑甲银纹琥珀眼）坐在画面左侧，右手悬在地图边缘]；
3-7s: [龙渊右手握住无名剑柄，镜头从中景缓慢推近]；
7-11s: [龙渊（下颌收紧）说：「该出发了。」]；
11-15s: [龙渊站直，椅脚摩擦木地板，镜头停在半身落幅]。
｜朝向：龙渊3/4侧面朝右
```

❌ 禁止写法：
- 输出 `【videoScript】`（系统解析器不识别）
- 抽象情绪："他心中充满了坚定"
- 多主体同时执行互不相关动作
- 时间段缺失、重叠，或总和不等于镜头时长
- 纯摄影机描述，没有角色或环境动作
- 有命名角色却缺少 `｜朝向：` 标注
- motionScript 内出现配乐/BGM描述

---

### 【对白】
**无对白的镜头可以不写此字段**（不要写"无"或空字段）。

格式：
```
- **【对白】**
  - 角色名(情绪/动作状态):「台词」
  - 另一角色名(情绪):「台词」
```

备注括号里可以写：情绪形容词、说话时的动作、声音状态（嘶吼/低语/颤抖）

---

### 【音效】
具体的声音事件，不是通用描述。

✅ 好的写法：
- `无名剑出鞘声，椅子在地板上的摩擦声，窗外鸟鸣`
- `蛇发鞭打声，金属碰撞声，美杜莎妖媚的笑`
- `格朗战斧砍腿：金属碰撞，狼人惨叫后退`

❌ 禁止写法：
- `环境声为主，音乐低铺，不抢对白`（通用废话）
- `背景音效`
- `无`

---

### 【字幕】
画面叠字，通常用于：
- 集首：地点字幕（`「铁崖边境·小镇」`）
- 时间标注（`「三天后」`、`「一年前·初见」`）
- 角色登场名牌（`「第七将军·白夜」`）
- 集尾情绪总结（`「差距·让我们更强」`）

**不是每个分镜都需要字幕**。只在信息必要时使用。

---

## 时间戳格式

```
**M:SS-M:SS|场景标题**
```

- 时间戳连续，无间隔（上一镜头的结束时间 = 下一镜头的开始时间）
- 第一个分镜从 `0:00` 开始
- 格式：`0:11-0:25|翠缇娜封位·灵瑶反击`

## 标准时长参考

| 镜头类型 | 推荐时长 |
|---------|---------|
| 开场建立镜头 | 9-15s |
| 动作战斗镜头 | 8-12s |
| 对话/情绪镜头 | 10-15s |
| 过渡/空镜 | 6-9s |
| 高潮决战镜头 | 12-15s |
| 结尾情绪落幕 | 10-15s |

**注水判断**：如果一个15秒的镜头，画面只写了"龙渊沉默地看着远方"——这就是注水。15秒的镜头需要有足够的动作层次或内心活动来填充。
