# S级质量标准完整规范

## 什么是S级分镜

S级分镜的核心指标：**每一个字段都在做且只做一件事，没有任何字段在用通用模板填位置。**

普通分镜写的是"发生了什么"，S级分镜写的是"具体到毫米级别的那一刻"。

---

## 禁用模板句（发现即替换）

以下句式是低质量的标志，出现在任何字段都必须重写：

### 【运镜】字段禁用句：
```
特写推镜：说话人面部，捕捉情绪细节，焦距压缩背景虚化
中景跟拍：捕捉XXX动作过程
固定中景：展示XXX
近景：XXX的反应
```
→ 替换为具体的英文摄影机指令（见 shot-format.md）

### 【画面】字段禁用句：
```
说话人面部表情随台词情绪流动，神情专注
XXX表情随台词变化
角色情绪丰富
```
→ 替换为具体的表情解剖（眉心怎么动、嘴角哪个方向、喉结有没有动）

### 【音效】字段禁用句：
```
环境声为主：风声、火焰或空间回响，音乐低铺，不抢对白
背景音效
环境底噪，人物动作 Foley（当这是唯一内容时）
```
→ 替换为具体的声音事件和声音质感

### 【motionScript】字段禁用写法：
```
角色深吸一口气，充满了坚定（抽象情绪）
镜头展现了XXX的美好（镜头主体不明）
四人同时展示各自的情绪（多主体模糊）
整段没有时间轴分段
时间段总和与镜头时长不一致
有命名角色但末尾没有｜朝向：标注
配乐响起 / 悲壮BGM / 弦乐渐强（音乐不得进入视频动作提示）
```

## 微表情技巧（S级的核心差异）

S级分镜用**身体解剖语言**替代情绪形容词。

### 标准微表情词汇库：

**手部细节：**
- 关节泛白（握拳时）
- 指尖微颤（紧张/愤怒压制时）
- 拇指在某物上无意识地摩挲（焦虑/思念）
- 手指逐一单独放下（从紧绷到放松的过程）

**面部细节：**
- 下颌角收紧/线条冷硬（压制情绪）
- 喉结轻动/上下动（吞咽/压抑话语）
- 眼睑轻颤（极度压制的情绪泄漏）
- 嘴角先抿紧再微开（想说话又忍住）
- 眉心细纹/眉间皱褶（苦涩/凝重）
- 睫毛在光下投出细小阴影（静止特写）

**姿态细节：**
- 肩线细微收紧/某侧肩膀下沉（情绪承压）
- 脊背微微挺直（拿定主意）
- 脚步节奏轻微不规则（内心失控的漏出）
- 步伐第N步比第N-1步稍慢半拍（情绪扰动）

### 写法对比：

❌ 普通写法：
```
白夜很震惊，他内心充满了愤怒，但表面上保持冷静
```

✅ S级写法：
```
白夜双手按在门板上，骨节因用力慢慢变白，然后指尖开始颤抖；
那个颤抖不是恐惧，是一种被压抑太久的愤怒终于找到了出口，
但出口太小，只能从指尖渗出来
```

## 摄影语言进阶

### 镜头节奏控制

不同情绪用不同的镜头运动速度传达：

| 情绪 | 镜头运动 | 节奏 |
|------|---------|------|
| 紧张/危机 | handheld + rapid intercutting | 快 |
| 沉重/悲痛 | static / very slow push | 极慢 |
| 觉醒/力量爆发 | low angle + tilt up | 慢→快 |
| 亲密/暧昧 | slow push in + shallow DOF | 慢 |
| 混乱战场 | 360 orbit + whip pan | 快 |
| 孤独/宿命 | slow pull back（镜头远离） | 慢 |

### 光线作为叙事工具

光线描述应该参与叙事，不只是"打亮场景"：

- **逆光**：轮廓感、宏大感、角色被命运推着走
- **侧光**：脸的阴阳面 = 内心的矛盾
- **炉火橙光**：温暖、友情、过去的记忆
- **绿色毒雾漫射**：压迫、异常、危险入侵
- **月光蓝白**：孤独、思念、内心独白
- **金色光爆**：神圣、力量觉醒、英雄时刻

## 对话写作规范

### 台词该说什么

S级台词的原则：**说角色在这一刻"不得不"说的话，不说角色"可以晚点说"的话。**

- 台词承载信息：推动情节 OR 揭示内心，二选一
- 一句话里不要同时完成两件事
- 情绪强烈的时刻：**让行动说话，台词从简或无**

### 禁用对话套路：
```
「我相信你！」（空洞的鼓励）
「不管发生什么，我都会在你身边。」（提前兑现情绪）
「我...我...」（过度省略号表达犹豫）
「大家小心！」（没有具体信息的喊叫）
```

### 好台词的特征：
- 说完之后，对方的处境发生了变化
- 有一个具体的动词或名词锚点（"我听到了魔王的计划" vs "有些事我必须告诉你"）
- 角色的说话方式和用词反映他的性格（白夜说话短促冷淡/格朗豪爽直白/灵瑶温而坚定）

## 首帧/尾帧高级规范

### 首帧的功能
首帧是 AI 图像生成的「初始条件」——它决定了整个镜头的起点状态。

必须包含：
1. 景别/角度（ECU/CU/MS/WS/低角度仰拍/俯拍）
2. 角色或场景的精确位置
3. 光线来源和质感
4. 情绪状态的身体表现（不是形容词）

### 尾帧的功能
尾帧是 AI 视频生成的「目标终点」——模型会在首帧和尾帧之间生成过渡运动。

首帧和尾帧的差异 = 这个镜头所做的情绪/动作位移。  
差异太小 → 镜头没有发生任何事情  
差异太大 → AI生成画面会跳跃不自然（建议同一景别内的状态变化）

### 首帧/尾帧配对示例：

```
【首帧】龙渊坐姿，地图在桌面，他的右手已经离开地图，向剑柄方向移动，侧面低角度
【尾帧】龙渊站立全身，无名剑背在背上稳稳竖立，琥珀眼看向窗外，逆光轮廓清晰
```
→ 从坐到站，从手离开地图到剑在背上，这个位移是合理的一镜内变化。

## 逻辑一致性清单

每集写完之后，对照以下清单检查：

### 角色层面
- [ ] 每个角色的武器和本集武器状态表一致
- [ ] 受伤的角色：伤势在本集内连续存在（不要中途消失）
- [ ] 角色只能知道他在这集里获得的信息（不要提前剧透）
- [ ] 角色的情绪转变有足够的铺垫（不要突然180度转弯）

### 物理/场景层面
- [ ] 时间连续：相邻集的时间跨度合理（白天→夜晚 vs 隔天）
- [ ] 地点连续：角色从A到B需要合理的时间（不要瞬移）
- [ ] 天气/光线：同一场景的不同分镜光线一致

### 剧情层面
- [ ] 每集有一个核心「转折点」
- [ ] 当集结尾留下下一集的情绪钩子
- [ ] 支线角色的出现有合理动机（不要无缘无故出现）

## 全集一致性管理

制作多集脚本时，建议维护以下记录表（在剧本开头）：

### 武器状态表
```
| 角色 | 第1-5集 | 第6-10集 | 第11+集 |
|------|--------|---------|--------|
| 龙渊 | 无名剑  | 无名剑   | 无双   |
```

### 角色入队时间表
```
第1集：龙渊、灵瑶
第4集：+翠缇娜
第6集：+格朗
第15集：+白夜、萝拉（后期加入）
```

### 已揭露信息表
```
第13集：白夜得知魔王献祭计划
第15集：龙渊队知道白夜的存在
```

这张表防止「信息穿越」——某角色知道他还不应该知道的事。
