# S级漫剧分镜脚本生成 Skill

本 skill 将故事方向扩写为可直接用于 AI 视频生成（Seedance/Kling/即梦）的 S 级分镜剧本。  
格式参考了经过数十轮打磨的30集完整项目，所有规范都经过真实制作流程验证。

---

## 工作流程

### Step 1：访谈用户（如信息不足）

如果用户只给出粗略方向，按以下顺序快速确认：

1. **故事类型**：奇幻/都市/武侠/科幻/爱情/悬疑？
2. **主角团**：核心角色名、外貌关键词、各自武器/道具（见下方视觉ID系统）
3. **集数规划**：要生成几集？每集时长（推荐 2:30-3:30）？
4. **世界观一句话**：背景设定的核心矛盾是什么？
5. **情绪基调**：热血/温柔/悬疑/黑暗/治愈？

如果用户已经提供了完整大纲，直接进入 Step 2。

---

### Step 2：建立角色视觉ID系统

**这是整个项目的基础锚点，必须在写第一个分镜前完成。**

每个角色需要一个固定的「视觉ID字符串」，格式：
```
[发色/发型] + [服装关键词] + [武器/道具关键词]（可选：肤色/眼色/体型）
```

这串字符串必须出现在每一个该角色的 `【videoScript】` 和 `【画面】` 中，让 AI 模型每次都能召回相同的外观。

**示例：**
| 角色 | 视觉ID字符串 |
|------|------------|
| 龙渊 | 黑甲银纹琥珀眼 / 无名剑（背负宽刃大剑）|
| 灵瑶 | 暗红旗袍黑靴露指拳套 |
| 翠缇娜 | 银发翠眸精灵弓箭 |
| 格朗 | 棕红大胡须重型头盔巨斧裂地 |
| 白夜 | 白发白和服霜魂野太刀 |
| 萝拉 | 紫发紫眸黑锥尾永夜法杖 |

武器/道具若有阶段性变化（如主角升级），必须建立「武器一致性表」记录每集用的版本。

---

### Step 3：规划卷结构与每集大纲

按「卷→集」两级结构组织故事：

```
# 第X卷：卷名（核心主题）
（3-5集为一卷，说明这个阶段的情感/剧情弧）

## 第N集：集名
**时长**：X分X秒
**剧情概要**：（2-3句，说明本集核心事件和情绪转折点）
**场景设定**：地点 / 时间 / 色调 / 氛围
**本集武器状态**：（每个角色当前武器）
```

每集的情绪弧必须有一个清晰的「转折点」——从A状态到B状态的那一刻，是整集的生命。

---

### Step 4：生成分镜

阅读 `references/shot-format.md` 获取完整分镜格式规范。  
阅读 `references/s-grade-rules.md` 获取S级质量要求和禁用模板列表。

**每集典型分镜数量**：
- 2分30秒集：9-12个分镜
- 3分集：12-15个分镜
- 每个分镜时间戳从 0:00 开始，精确到秒

---

### Step 5：时长与质量自查

完成每集分镜后，执行以下检查：

**时长检查：**
- 所有分镜时间戳加总 = 集数标注时长 ✓
- 每个分镜：画面内容能否填满这段时间？（避免注水）
- 内容太多撑不开时长？→ 拆分分镜

**质量检查（对照禁用模板列表）：**
- 没有"说话人面部表情随台词情绪流动"
- 没有"中景跟拍：捕捉XXX动作过程"  
- 没有"环境声为主，音乐低铺不抢对白"（音效字段不能用通用描述）
- `【运镜】` 和 `【画面】` 内容不重复，各司其职
- `【首帧】` 和 `【尾帧】` 不能相同，必须体现镜头的起止状态

**逻辑检查：**
- 武器状态在本集内保持一致
- 角色只知道他们应该知道的事
- 受伤/物品的状态在相邻集之间连续

## 关于AIComicBuilder系统的AI扩写功能

本项目的 AIComicBuilder 系统提供 `/api/projects/[id]/generate` 端点，可对每个分镜自动生成 `videoScript`、`首帧`、`尾帧` 等字段。

如果用户需要调用系统的AI扩写功能：
- 参考 `AGENTS.md` 中的 `generate/route.ts` 路由说明
- 该路由使用 SSE 流式输出，支持 `enhancePrompts` 开关
- 生成前会调用 `enhanceImagePrompt`/`enhanceVideoPrompt` 优化提示词
- 角色图片通过 `filterShotCharacters` 精确匹配，无匹配时传空列表（不 fallback）
