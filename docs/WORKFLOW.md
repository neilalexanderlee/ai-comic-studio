# AI漫剧工坊 — 制作工作流

> **版本**：v0.5（场景资产 + Toonflow 首帧对齐）  
> 三帧字段含义与衔接规则见 [ARCHITECTURE-FRAMES.md](./ARCHITECTURE-FRAMES.md)。  
> 提示词分层见 [ARCHITECTURE-PROMPTS.md](./ARCHITECTURE-PROMPTS.md)。

---

## 工作流总览

```
① 导入剧本
② 解析角色 + 上传定妆图 + 上传音色参考（可选）
③ 进入分集 → AI 解析分镜（含质量评级 A/B/C/D）
④ 场景管理 → 「从分镜提取」→ 勾选确认 → AI 生成场景参考图
   └─ 回到分镜页，为每个分镜卡「关联场景」
⑤ 设置生成参数（画风 / AI增强 / 镜头衔接）
⑥ 生成首帧（点「生成画面」→ 自动注入角色定妆图 + 场景参考图）
⑦ 自动分配 Track → Seedance 多参批量生成视频
⑧ 视频编辑器（时间线 + 字幕 + BGM + 转场）→ 导出
```

---

## 详细步骤

### 第一步：导入剧本

在项目页面导入剧本，系统自动识别角色列表和分集结构。

**剧本音频字段规范：**

| 标签 | 作用 | 传给视频模型？ |
|------|------|----------------|
| `【音效】火焰噼啪、金属碰撞` | 场景级同步音效 | ✅ 注入视频 prompt，模型原生生成 SFX |
| `【背景音】温暖弦乐` | BGM 情绪注记 | ❌ 仅供后期选曲参考，系统自动剔除 |
| videoScript 里写"配乐响起" | — | ❌ 同上，系统自动剔除 |

> BGM 的剔除机制与 Toonflow 一致：视频 prompt 只传音效（SFX），不传背景音乐描述，Seedance 原生生成环境音/音效但不生成 BGM。

**剧本质量提示：** 场景切换处写过渡动作，不要硬切。

---

### 第二步：解析角色 + 上传定妆图 + 上传音色参考

在"角色"页面：

1. 点击 **解析角色** — AI 从剧本提取命名角色，生成外貌描述与 9 维度音色描述
2. 为每个角色上传 **定妆图**（推荐 4 视图：正面 / 四分之三 / 侧面 / 背面）
3. 为每个角色形态卡片上传 **音色参考音频**（MP3 / WAV / M4A，可选）

**音色参考的作用：**

| 状态 | Seedance 多参模式音色处理 |
|------|--------------------------|
| 有音频文件 | @参考N 音频绑定，Seedance **克隆**该音色生成对白 |
| 无音频，有 voiceHint 文字 | 文字描述直接照搬（如"男声，约25岁，声音低沉沙哑"）|
| 两者都没有 | 系统按角色特征自动生成 9 维度音色描述 |

> 上传真实音频后，角色说话的声音在视频里会克隆该音频的音色，比文字描述效果好一个数量级。

---

### 第三步：进入分集 → AI 解析分镜

1. 进入目标分集
2. 点击 **解析分镜**

**解析后输出的字段：**

| 字段 | 说明 |
|------|------|
| `prompt` | 场景描述（情节/环境） |
| `startFrameDesc` | 首帧静帧构图描述 |
| `endFrameDesc` | 尾帧静帧构图描述（可选，供 Kling 首尾帧插值使用）|
| `videoScript` | Seedance 格式运动散文 |
| `motionScript` | 时间线动作脚本（含 `｜朝向：` 标注）|
| `cameraDirection` | 运镜指令 |
| `duration` | 时长（秒）|
| `soundEffectNote` | 音效（来自 `【音效】` 标签）|
| `bgmNote` | BGM 情绪注记（来自 `【背景音】`，不传给视频模型）|
| `dialogues[].type` | 台词类型：`dialogue`（对白）/ `os`（内心OS）/ `vo`（画外音VO）|

**解析结束后，系统自动运行质量监督（6红线校验）：**

- 🟢 **A级**（严重0，警告≤2）— 直接可用，显示绿色成功 toast
- 🟡 **B级**（严重0，警告≤5）— 小修后可用，显示橙色 toast + 问题摘要
- 🔴 **C/D级** — 显示橙色 toast + 问题列表，建议重新解析

**质量问题排查方向（C/D级时）：**

| 常见问题 | 原因 | 方案 |
|---------|------|------|
| startFrameDesc 缺少光影/情绪信息 | 未按四要素格式生成 | 单镜「重新生成文本」，确保首帧自包含主光+情绪解剖 |
| 含禁用模板语 | "神情专注""眼神复杂"等 | 单镜「重新生成文本」|
| 有命名角色但 motionScript 无 `｜朝向：` | 朝向标注缺失 | 单镜「重新生成文本」|

### 第四步：场景管理

> 此步骤需要第三步已完成分镜解析，「从分镜提取」才有数据可用。

在「场景」页（导航第4项）：

1. 点击 **「从分镜提取」** — LLM 扫描本集所有分镜的场景描述和光影氛围，识别独立场景地点，自动生成符合规格的场景描述
2. 在弹出的确认面板中：勾选要创建的场景，可以编辑名称和描述
3. 点「创建选中的 N 个场景」
4. 为每个场景点 **「AI 生成参考图」** — 用场景描述 + 项目画风生成场景锚定图
5. 也可手动 **上传图片** 作为场景参考图

**回到分镜页关联场景：**

展开任意分镜卡的「分镜描述」区，点击 📍 按钮，选择该分镜所属场景。关联后生成首帧时，场景参考图会自动作为 `@图N 为{场景名}场景` 注入 prompt。

**场景描述写法规范（用于 AI 生成参考图）：**

- 只描述空间环境，**不出现角色**
- 包含：空间结构 + 关键道具/建筑 + 光线时段 + 材质质感 + 氛围词
- 40-80 字，精炼聚焦
- 示例：`青石板路纵深延伸，两侧低矮茅草屋，路旁一口青石井，远处稻草堆，冷蓝晨光从左侧低角度斜照，石板路面泛冷青色光泽，晨雾未散`

---

### 第五步：设置生成参数

在分镜页顶部「生成设置」区：

| 开关 | 含义 | 推荐 |
|---|---|---|
| **AI 增强** | 生成图片/视频前用 AI 优化 prompt | ✅ 开启 |
| **镜头衔接（视频尾帧）** | 视频完成后自动把 `cut_point` 直拷为下一镜 `anchor_first` | 默认关；连续落幅时开启 |

---

### 第六步：生成首帧

**对齐 Toonflow Seedance 主流程：「生成画面」= 只生成首帧。**

点击分镜卡「生成画面」按钮，系统用以下信息生成首帧参考图：

```
@图1 为{角色A}角色 @图2 为{角色B}角色 @图3 为{场景名}场景,

【画面】{startFrameDesc 全文}，{从 motionScript 提取的角色朝向}。

【光影】{从 startFrameDesc 自动提取的主光关键词}。

【风格】{art-styles/{visualStyle}/storyboard.md 风格锚定词}，禁止画外字幕。

保持 @图1、@图2 面部特征、发型、服饰与参考图完全一致。
```

**设计要点（完整 Toonflow 对齐）：** `startFrameDesc` 是唯一画面来源，必须自包含四要素——景别/视角 + 角色精确位置姿态 + 主光（颜色+方向+来源）+ 情绪的身体解剖表现（禁用「神情坚定」等形容词）。`emotion`/`framing`/`lightingAtm` 均已从数据库移除（migration 0042/0043），所有视觉信息统一写入 `startFrameDesc`。

- **角色定妆图**（`@图1`…）：自动从角色资产中查找，仅注入本镜出现的角色
- **场景参考图**（最后一个 `@图N`）：若分镜已关联场景且场景有参考图，自动追加
- 若未关联场景，仅注入角色定妆图

**Kling 首尾帧插值（可选）：**

若使用 Kling 等支持关键帧插值的视频模型，可在首帧生成后通过分镜帧区域的单帧控件单独「生成尾帧」。有 `anchorLastAi` 时，生成视频自动切换到首尾帧插值模式；无则使用首帧参考模式。

**参考图选择器：**

在分镜帧区域点击 🔄 按钮：
- 选「独立生成」→ 仅用本镜描述 + 定妆图 + 场景参考图
- 选「分镜 N · 首帧/AI尾帧/视频尾帧」→ AI 参考该帧重绘，保持视觉连续性

### 第七步：Seedance 多参批量生成视频

利用 Seedance 2.0 多参模式一次生成多镜连贯视频。

**步骤：**

1. 点击 **「自动分配 Track」** — 系统按累计时长 ≤ 15s 将连续分镜分组（T1 / T2 / T3...）
2. 每张分镜卡序号下方显示 **Track 徽章**（紫色）
3. 逐 Track 点击「生成本组视频」（或继续使用单镜生成）

**Seedance 多参提示词格式（自动生成）：**

```
画面风格和类型: 2D成熟都市言情动画，2D赛璐璐上色，电影级光影

参考定义:
@参考1: 角色甲，[外貌简述]
@参考2: 角色乙，[外貌简述]，参考音频为：@参考3   ← 音色克隆
@参考4: 石板路村口，场景            ← 场景资产（已关联时自动注入）
@参考5: 分镜1（首帧图）
@参考6: 分镜2（首帧图）

生成一个由以下 2 个分镜组成的视频:

分镜1 10s: 时间：清晨，场景：石板路村口，镜头：中景，...，角色甲 说：「台词」音色：@参考3。...
分镜2 8s: ...
```

| 台词类型 | 格式 | 嘴型行为 |
|---------|------|----------|
| `dialogue`（对白）| `角色 说：「...」` | 嘴部开合 |
| `os`（内心独白）| `角色 内心OS：「...」` | 嘴部紧闭 |
| `vo`（画外音）| `角色 画外音VO：「...」` | 嘴部紧闭或不在画面 |

**也可以继续使用单镜生成：** 按原有方式逐镜点「生成视频」，路径兼容，不受 Track 影响。

---

### 第八步：视频编辑器

浏览器端视频编辑器，无需导出到外部软件即可完成基础后期。

**入口：** 分镜页顶部「视频编辑器」按钮（Layers 图标）

**功能：**

| 模块 | 支持内容 |
|------|---------|
| **时间线轨道** | 视频轨（5条）/ 音效轨（3条）/ 字幕轨（2条）/ BGM 轨（1条）|
| **素材库** | 项目分镜视频（自动加载）/ 本地音频上传 / 字幕添加 |
| **转场** | 14种（淡入淡出 / 溶解 / 滑动 / 擦除 / 缩放 / 模糊 / 圆形等）|
| **特效** | 8种（淡入 / 淡出 / 放大 / 缩小 / 闪烁 / 抖动等）|
| **字幕编辑** | 文字内容 / 字号 / 颜色 / 垂直位置 / 淡入淡出 |
| **音频控制** | 音量 / 淡入淡出时长 |
| **实时预览** | Canvas 渲染（字幕叠加 / 30fps）|
| **导出** | WebM 格式（MediaRecorder）|

**推荐工作流：**

1. 分镜视频全部生成完毕后，进入编辑器
2. 素材库→视频标签 → 依次点击分镜添加到时间线（或手动调整顺序）
3. 字幕会根据台词自动初始化（AI 解析分镜时已提取）
4. 素材库→音频标签 → 上传 BGM，拖入 BGM 轨道
5. 素材库→转场标签 → 点击转场类型，自动插入到最后两个片段之间
6. 实时预览确认效果 → 导出 WebM

> 导出的 WebM 可进一步在剪映/PR/DaVinci 做细节调整和最终渲染。

---

### 第九步（可选）：ffmpeg 合并

若跳过编辑器，也可直接在分镜页点「合并视频」，ffmpeg 自动拼接全集并做响度归一化（-14 LUFS）和淡入淡出（0.5s/1s）。

## 单镜头操作速查

| 想做什么 | 操作 |
|---|---|
| 重写 videoScript/首尾帧描述 | 分镜卡 → **重新生成文本**（含6重校验 + 朝向标注）|
| 恢复到原始剧本文本 | 分镜卡 → **从剧本还原** |
| 改台词类型（对白→OS→VO）| 分镜卡台词区 → 下拉选择器 |
| 关联场景 | 分镜卡展开「分镜描述」→ 📍 按钮 → 选择场景 |
| 用上一镜视频尾帧当本镜首帧 | **承接上一镜尾帧** |
| 用上一集最后一镜尾帧 | 第二集第1镜 → **承接上一集尾帧** |
| 参考任意他镜帧生成首帧 | 首帧🔄 → **选择参考图** |
| 单独生成尾帧（Kling 首尾帧插值用）| 分镜帧区域 → 单帧控件 → **生成尾帧** |
| 为角色上传音色参考 | 角色页 → 形态卡片 → **上传音色参考** |
| 批量分配 Track | 分镜页 → **自动分配 Track** |

## 故障排查

| 现象 | 原因 | 解决方案 |
|---|---|---|
| 解析后质量评级 C/D | 字段缺失或禁用模板词 | 重新点「解析分镜」，或逐镜「重新生成文本」|
| 首帧 @图N 编号错位 | 资产顺序问题 | 确认角色定妆图已上传，重新生成首帧 |
| 首帧里出现不属于该镜的角色 | 角色名是另一角色名的前缀（如"角色甲"/"角色甲父亲"）| 已自动处理（最长优先匹配），如仍有问题检查角色命名 |
| 首帧场景参考图未注入 | 该分镜未关联场景，或场景尚未生成参考图 | 场景页生成参考图 → 分镜卡关联场景 |
| Seedance 多参音色不对 | voiceHint 文字描述不精确 | 上传 MP3/WAV 音色参考（角色页）|
| Track 分组后视频混乱 | 分镜顺序不连续 | 重新点「自动分配 Track」后再生成 |
| 视频编辑器字幕不显示 | 字幕轨道被静音 | 轨道标签区点击取消静音 |
| WebM 导出音频缺失 | MediaRecorder 不含音频轨 | 暂时限制：需在外部软件合成音频 |
| 生成的单段视频有 BGM | 旧版 videoPrompt 含配乐描述 | 点「从剧本还原」重新解析，再「重新生成文本」|
| 群演→主角切换割裂 | 误把群演 cut_point 当下镜首帧 | 不点「承接上一镜尾帧」；独立生成主角首帧 |
| 相邻镜头角色外貌不一致 | 定妆图未上传，或角色未正确匹配 | 上传定妆图；重新生成首帧 |
| 视频里角色比例变形 | 视频模型局限 | 在 videoScript 加比例描述 |
| ENOENT / 帧文件缺失 | 磁盘文件已删但 DB 有路径 | 分镜卡红框「文件缺失」→ 重生对应帧 |
